**ببینید اگه سایت **
***👇***
***👇***
***👇***
[https://cloudflare-ech.com](https://cloudflare-ech.com/)
براتون تو مرورگر باز میشه یعنی همچنان روش ECH کار میکنه و دامنش قابل استفادس ، الان فقط اومدن جلوگیری کردن از اینکه شما بتونید از طریق plain DNS کلید ECH رو بگیرید.
که خب من از قبل فکرش رو کرده بودم و echSockopt رو در هسته‌ی اصلی Xray-core و echOutbound رو در PattN/PattNG پیاده سازی کرده بودم.
///
[دانلود نسخه جدید Pattng ***👉***](https://t.me/patt_channel_x/185)
***👉***
بنابراین برای استفاده از روش ECH در حال حاضر کافیه قسمت های زیر را بزنید به جاهای مورد نظر :
echConfigList :
`cloudflare-ech.com+h2c://1.1.1.1/dns-query`
و قسمت
echOutbound :
{
      "tag": "tls-repack-dns",
      "protocol": "direct",
      "settings": {
        "redirect": "1.1.1.1:443"
      },
      "streamSettings": {
        "security": "tls",
        "tlsSettings": {
          "serverName": "www.microsoft.com",
          "verifyPeerCertByName": "fromMitM,www.microsoft.com",
          "alpn": ["fromMitM"],
          "fingerprint": "chrome"
        }
      }
    }
قرار بدید ، از آخرین نسخه PattN و PattNG هم استفاده کنید. 
(PattNG P67, PattN P34)
