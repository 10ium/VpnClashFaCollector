### 🕒 2026-06-20 07:14:26 UTC
***💥***
 آموزش ساخت پنل لوفی (با قابلیت تعیین حجم و روز)
دوستان، توی این آموزش یاد می‌گیرید چطور خیلی راحت و رایگان، پنل لوفی رو روی سرورهای Railway بالا بیارید. تمام مراحل رو قدم‌به‌قدم براتون نوشتم که به مشکل نخورید.
***🔗***
 لینک‌های مورد نیاز:
سایت گیت‌هاب: 
[GitHub](https://github.com/)
سورس پروژه لوفی: 
[LUFFY_PANEL](https://github.com/luffy-sh-op/LUFFY_PANEL)
سایت ریل‌وی: 
[Railway](https://railway.com/)
***1️⃣***
 مرحله اول: آماده‌سازی گیت‌هاب و فورک پروژه
قبل از هر چیز باید یک اکانت گیت‌هاب داشته باشید. (اگر ندارید، می‌تونید با ایمیل فیک از  سایت Atomic Mail راحت ثبت‌نام کنید).
حالا وارد لینک پروژه لوفی بشید.
***💡***
 نکته مهم: برای اینکه کارتون راحت‌تر بشه، مرورگر گوشی رو روی حالت Desktop Site (سایت مخصوص رایانه) بزارید تا دکمه‌ها درست دیده بشن.
توی صفحه پروژه، از اون بالا سمت راست روی دکمه Fork بزنید. اسم کادر رو تغییر ندید و روی دکمه سبز رنگ Create fork کلیک کنید تا پروژه کپی بشه توی اکانت خودتون.
***2️⃣***
 مرحله دوم: اتصال به سایت Railway و ساخت سرور
وارد سایت 
[railway.com](http://railway.com/)
 بشید و روی دکمه بنفش‌رنگ Deploy بزنید.
از لیست باز شده، گزینه اول یعنی GitHub repository رو انتخاب کنید و بعد روی Login with GitHub بزنید.
یک صفحه جدید براتون باز میشه؛ روی دکمه سبز رنگ Authorize بزنید تا ریل‌وی به گیت‌هاب شما متصل بشه.
بعد از چند ثانیه به سایت ریل‌وی برمی‌گردید. صفحه قوانین رو تا آخر بکشید پایین تا دکمه I agree with Railway's Terms of Service پررنگ بشه و روش بزنید.
در صفحه بعدی هم چند ثانیه صبر کنید و روی دکمه I will not deploy any of that بزنید.
***3️⃣***
 مرحله سوم: دسترسی‌ها و تایید ایمیل
حالا روی گزینه Configure GitHub App بزنید. صفحه جدیدی به اسم Install & Authorize Railway App براتون باز میشه.
حتماً دقت کنید که گزینه اول روی All repositories باشه. حالا دکمه سبز پایین صفحه یعنی Install & Authorize رو بزنید.
توی این مرحله یک کد تایید به ایمیل گیت‌هاب شما فرستاده میشه؛ اون کد رو توی کادر مربوطه وارد کنید تا اکانتتون وریفای بشه.
***4️⃣***
 مرحله چهارم: ساخت و ورود به پنل
دوباره به سایت ریل‌وی هدایت می‌شید و لیست پروژه‌هاتون رو می‌بینید. روی پروژه فورک شده یعنی luffy panel کلیک کنید تا شروع به ساخت سرور کنه.
بین ۱ تا چند دقیقه صبر کنید تا مراحل انجام بشه. هر وقت نوشت Deployment successful یعنی کار تمومه!
همون بالای صفحه، آدرس پنل شما نوشته شده که آخرش پسوند 
[railway.app](http://railway.app/)
 داره. این آدرس رو کامل کپی کنید.
آدرس رو توی یک تَب جدید مرورگر پیست (Paste) کنید و آخرش عبارت login/ رو اضافه کنید (مثلاً: 
[my-panel.railway.app/login](http://my-panel.railway.app/login)
) تا صفحه ورود باز بشه.
***🔑***
 رمز عبور پیش‌فرض پنل: admin
***5️⃣***
 مرحله پنجم: ساخت کانفیگ و اضافه کردن آی‌پی تمیز
بعد از ورود به پنل، همه‌چیز طبق فیلم مشخصه؛ به بخش Inbounds برید و کاربر جدید بسازید.
بعد از ساخت کاربر، با زدن دکمه Copy می‌تونید کانفیگ اصلیش رو بردارید. برای لینک ساب هم روی دکمه Sub بزنید.
سمت راست بخش Inbounds، یک بخش به اسم Clean IPs وجود داره. واردش بشید، روی Add بزنید و آی‌پی‌های تمیز رو به صورت عمودی (زیر هم) وارد و تایید کنید تا روی ساب کاربر اعمال بشن.
***⚠️***
 توجه: آی‌پی تمیز کلودفلر برای این پنل جواب نمیده! آی‌پی‌های تمیز مخصوص ریل‌وی رو توی پست بعدی براتون قرار میدم.
***🛠***
 آموزش تغییر لوکیشن سرور (در صورت ضعیف بودن سرعت)
اگر احساس کردید سرعت یا پینگ کانفیگ‌ها خوب نیست، می‌تونید لوکیشن سرور رو عوض کنید:
برگردید به صفحه اصلی پروژه‌تون توی سایت 
[railway.com](http://railway.com/)
.
از منوی بالا سمت راست وارد بخش Settings بشید.
یکم بیایید پایین (طبق فیلم) تا به بخش Regions & Replicas برسید.
لوکیشن سرور رو به یک کشور دیگه تغییر بدید.
در آخر از پایین صفحه روی Deploy بزنید و چند دقیقه صبر کنید تا تغییرات روی سرور اعمال بشه.
