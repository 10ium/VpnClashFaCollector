### 🕒 2026-10-06 20:27:47 UTC
نسخه 1.0.9 — Aurora Edition از پنل حامد منتشر شد !
***🔧** باگ‌های رفع‌شده*
**۱. باگ Master Key**
تغییر Master Key ذخیره می‌شد ولی موقع لاگین نادیده گرفته می‌شد. الان پسورد از تنظیمات خونده می‌شه و تغییرش کاملاً اعمال می‌شه.
**۲. باگ پسورد مدیران**
ویرایش رمز root کار نمی‌کرد. الان رمز جدید با salt تازه ذخیره می‌شه و ویرایش رمز خود root هم ممکنه.
**۳. خطای 1011 در WebSocket**
در قطع ناگهانی اتصال، کد خطای 1011 فرستاده می‌شد. الان همه کدها به 1000 تبدیل می‌شن و اتصال پایدارتره.
**۴. دکمه‌های بی‌واکنش**
بعضی دکمه‌ها کار نمی‌کردن. الان همه با onclick مستقیم کار می‌کنن.
**۵. باگ Port Logic**
پورت‌ها همیشه 443 برمی‌گشتن. الان اولویت‌بندی درست داره: کاربر ← ISP ← سراسری.
**۶. باگ Escape در HTML**
مشکل بک‌اسلش در string های HTML برطرف شد.

***🎨** تغییرات ظاهری*
**صفحه لاگین**
طراحی split-screen با انیمیشن Aurora، کارت شیشه‌ای و پس‌زمینه متحرک.
**داشبورد پنل**
ساید‌بار شناور، کارت‌های آماری Bento Grid، پالت فرمان با Ctrl+K و انیمیشن‌های نرم.
**صفحه اشتراک**
اضافه شدن کارت "Your Subscription" که خلاصه وضعیت رو نشون می‌ده:
- روزهای باقی‌مانده
- نوار ترافیک با انیمیشن
- تاریخ انقضا
- مصرف امروز
- شناسه و مصرف کل
**لوگوی اپ‌ها**
لوگوی واقعی اپ‌های پیشنهادی (Karing، NekoBox، v2rayNG، Clash Meta، Shadowrocket، Streisand، Hiddify) از GitHub گرفته می‌شه. اگر لود نشد، حرف اول نمایش داده می‌شه.

آموزش ساخت پنل CFnew 
***👆***
***👆***
اختصاصی کانال خودمون 
***🔥***
برای اتصال بهتر هر روز آیپی مناسب میزارم تا در پنل استفاده کنید .
درود دوستان 
تمامی مراحل در ویدیو به وضوح مشخص هست و من برای راحتی شما متغیر ها رو یک بار اینجا اشاره میکنم و لینک ها رو میذارم مجدد
1-وارد حساب کلودفلیر خودتون بشید 
2-طبق ویدیو از قسمت storage and database یک worker KV برای خودتون بسازید 
(
***❗️***
نکته : از گذاشتن اسامی همچون cf و vpn و مشابه اونها خودداری کنید)
3-بعد از قسمت worker and pages روی creat application بزنید و بعد از اون روی start with hello world بزنید و نام انتخاب کنید و نکته بالا رو هم مجددا رعایت کنید
4-حالا edit code بزنید و کد رو یا کپی و پیست کنید یا آپلود کنید بعد از دیدن نوار سبز میتونید خارج بشید 
5-روی add binding کلیک کنید و kv namespace  اضافه کنید (دقت کنید که حرف C بزرگ نوشته باشید)
6-از settings روی Variables and Secrets ضربه بزنید و در قسمت اول حرف u کوچک وارد کنید و در قسمت دوم UUID وارد کنید
7-روی visit site بزنید و در پنل uuid که ست کردید وارد کنید و به لینک ها دسترسی خواهید داشت
نیازی به تغییر کانفیگ نیست 
***👉***
