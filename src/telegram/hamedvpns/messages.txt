> ↪️ **Forwarded**

**جمع بندی راه‌های کنونی اتصال به کلودفلر بر روی فایروال همراه اول:**
1. CDN/WORKER with IPv6
در صورت داشتن IPv6 و در صورتی که دامنه‌ی شخصی فیلتر نشده دارید، و یا از دامنه‌ی 
[workers.dev](http://workers.dev/)
.* استفاده میکنید، میتوانید از این روش استفاده کنید (دامنه 
[pages.dev](http://pages.dev/)
.* به طور کلی فیلتر است).
برای استفاده ابتدا echConfigList و cipherSuites و finalMask را پاک کنید، فینگرپرینت را روی chrome قرار دهید و سپس از یک آدرس IPv6 به طور مثال
`2a06:98c1:3101::6812:202f`
استفاده کنید.
2. WARP with IPv6
از قسمت add aether ابتدا پروتوکل را روی wireguard قرار دهید، نوع آیپی را IPv6 انتخاب کنید، اسکن کنید، بعد از پیدا شدن آیپی اسم انتخاب کنید و سیو کنید.
3. MASQUE/H2
از قسمت add aether پروتوکل را روی MASQUE-HTTP/2 قرار دهید،  سپس اسکن کنید، و بعد از پیدا شدن آیپی اسم انتخاب کنید و سیو کنید.
////////////////////
**جمع بندی راه‌های کنونی اتصال به کلودفلر بر روی فایروال ایرانسل:**
1. CDN/WORKER with F&F method
ابتدا echConfigList را پاک کنید، از یک آدرس مناسب به طور مثال
`188.114.98.0`
استفاده کنید، finalMask را tlshello-0-len (همان مقدار متد F&F) قرار دهید و برای فایروال ایرانسل حتما باید cipherSuites را روی semi-python (همان مقدار متد F&F) و فینگرپرینت را روی unsafe قرار دهید، همچنین دقت کنید که مقدار ALPN را درست انتخاب کرده باشید (http/1.1 برای ws و h2,http/1.1 برای XHTTP)
* سایر روشها روی فایروال ایرانسل با محدودیت سرعت آپلود مواجه هستند.
2. WARP 
همان مراحل فایروال همراه اول، منتها روی فایروال ایرانسل میتوانید از هر نوع IPی استفاده کنید.
3. MASQUE/H2 
دقیقا همان مراحل فایروال همراه اول 
////////////////////
**دقت کنید در برخی مناطق سیم کارتتون میتونه همراه اول باشه ولی فایروالتون ایرانسل باشه و بالعکس سیم کارتتون میتونه ایرانسل باشه ولی فایروالتون همراه اول باشه.**
سایر نت ها هم معمولا از یکی از این دو فایروال استفاده میکنند.

### 🕒 2026-10-22 09:05:46 UTC
***🚀***
 Satelite One
یک کلاینت، ۳ هسته برای اندروید 
اگه از کلاینت‌های معمولی خسته شدید، Satelite One یه پروژه جالبه که چندتا قابلیت رو یکجا آورده.
این کلاینت اندرویدی از سه هسته پشتیبانی می‌کنه :
***🔹***
 sing-box 1.14
***🔹***
 mihomo (Clash Meta)
***🔹***
 Xray v26
و نکته جالب اینه که می‌تونید حین اجرا بین هسته‌ها جابه‌جا بشید.
***🔥***
 چه چیزی نسبت به خیلی از کلاینت‌ها متفاوتش می‌کنه؟
***🧠***
 
**Smart Modeبرنامه هر ۳۰ ثانیه وضعیت نود فعلی رو بررسی می‌کنه و اگر تأخیر زیاد بشه، خودش نودهای دیگه رو بررسی و در صورت مناسب بودن، به گزینه بهتر سوییچ می‌کنه.**
***📡***
 تست واقعی نودها
فقط به Ping اکتفا نمی‌کنه؛ نودها رو با اتصال واقعی هم بررسی می‌کنه تا انتخاب بر اساس وضعیت واقعی اتصال باشه.
***⚙️***
 سه هسته در یک برنامه
اگر یک کانفیگ با sing-box بهتر کار کرد، از همون استفاده کنید؛ اگر لازم بود mihomo یا Xray رو امتحان کنید. همه داخل یک کلاینت.
***📦***
 پشتیبانی از فرمت‌های مختلف
Clash YAML، Base64 و لینک‌های مختلف مثل:
VLESS / VMess / Trojan / Shadowsocks / Hysteria2 / TUIC / AnyTLS و...
***🔄***
 آپدیت خودکار Subscription
می‌تونه Subscriptionها رو در بازه‌های مختلف به‌صورت خودکار آپدیت کنه.
***🧺***
 ترکیب چند Subscription
چند Subscription رو می‌تونید با هم ترکیب کنید و نودها رو داخل یک مجموعه داشته باشید.
***📱***
 پروکسی برای هر اپ
می‌تونید مشخص کنید کدوم برنامه‌ها از VPN استفاده کنن و کدوم مستقیم به اینترنت وصل بشن.
***🌐***
 Routing داخلی
امکان Rule برای دامنه‌ها، اتصال مستقیم، پروکسی و انتخاب نود مشخص وجود داره.
***🔐***
 DNS و TUN
برای هر سه هسته پیاده‌سازی جداگانه داره و از TUN استفاده می‌کنه. برای mihomo و Xray هم از hev-socks5-tunnel به‌عنوان پل TUN به SOCKS5 استفاده شده.
***📊***
 مانیتورینگ اتصال
نمایش IP خروجی، تأخیر، مصرف ترافیک، اتصال‌های فعال و لاگ‌های زنده.
مزیت اصلی Satelite One اینه که به‌جای اینکه فقط یک هسته خاص رو با امکانات معمولی ارائه بده، sing-box + mihomo + Xray رو در یک محیط واحد جمع کرده و روی انتخاب هوشمند نود، تست اتصال و مدیریت Subscription هم امکانات نسبتاً کاملی گذاشته.
