** آموزش اشتراک‌گذاری اینترنتِ VPN دو برنامه v2rayNG یا NPV Tunnel روی دستگاه‌های دیگر**
 
**مرحله اول: پیدا کردن پورت در اپلیکیشن:**
• در v2rayNG یا نپستر : وارد منو (سه نقطه) شوید -> Settings -> به دنبال Local Proxy Port بگردید. (معمولاً روی 10808 است).
**مرحله دوم: فعال‌سازی هات‌اسپات و اتصال**
1. ابتدا Hotspot (نقطه اتصال)گوشی خود (که VPN دارد) را روشن کنید.
2.با دستگاه دوم (گوشی دیگر، لپ‌تاپ یا کنسول) به وای‌فای گوشی اول وصل شوید.
**مرحله سوم: پیدا کردن IP روتر (Gateway):**
***🤖***
• در اندروید (دستگاه دوم): به تنظیمات WiFi بروید -> روی نام وای‌فای وصل شده بزنید -> در بخش جزئیات به دنبال Gateway یا Router IP بگردید (معمولاً چیزی شبیه 
`192.168.43.1`
 است).
+ روش دیگر نصب برنامه Every Proxy و فعالسازی گزینه http proxy قسمت ipv4 (داخل تصویر وسطی)
***🍏***
• در آیفون: به تنظیمات WiFi بروید -> روی علامت (i) جلوی نام وای‌فای بزنید -> به پایین اسکرول کنید تا آدرس روبروی Router را ببینید.
**مرحله چهارم: ست کردن پروکسی روی دستگاه مقصد**
***⌨***
 اگر 
**مقصد ویندوز**
 است:
1. در سرچ ویندوز بنویسید Proxy Settings و آن را باز کنید.
2. بخش Manual Proxy Setup را روشن کنید.
3. در قسمت Address، همان "آی‌پی روتر" که پیدا کردید را بزنید.
4. در قسمت Port، عدد پورت (مثلاً 10808) را وارد و Save کنید.
***📲***
 اگر 
**مقصد گوشی دیگر**
 است:
1. به تنظیمات WiFi بروید و روی وای‌فای وصل شده طولانی لمس کنید (Modify Network).
2. بخش Proxy را از حالت None به Manual تغییر دهید.
3. در قسمت Proxy Hostname، آی‌پی روتر و در قسمت Port، عدد پورت را بزنید و ذخیره کنید.
***🛡***
 
**تلگرام دستگاه دیگر:**
اگر فقط قصد استفاده در تلگرام دستگاه دیگر دارید گزینه Add Proxy داخل تلگرام قسمت Socks5 رو فعال و ایپی و پورت رو وارد کنید.
در اپلیکیشن v2rayNG، حتماً گزینه Allow connections from the LAN را در تنظیمات فعال کنید تا اجازه دسترسی به سایر دستگاه‌ها داده شود.
