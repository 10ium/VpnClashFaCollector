 همراه با قابلیت‌های کاربردی جدید، ارتقای سطح امنیت و بهینه‌سازی‌های گسترده در رابط کاربری به‌طور رسمی منتشر شد.

### 
***🚀***
 
**مهم‌ترین تغییرات و قابلیت‌های جدید:**
***1️⃣***
 
**امکان به‌روزرسانی مجزای ورکر (Worker Update Only):**
از این پس نیازی به ساخت مجدد پایگاه‌داده (D1) یا تنظیم دوباره رمز عبور نیست. کاربران می‌توانند تنها با یک کلیک، کد ورکر فعلی خود را به آخرین نسخه منتشرشده در گیت‌هاب ارتقا دهند.
***2️⃣***
 
**مدیریت هوشمند پنل‌ها و «به‌روزرسانی سریع» (Quick Update):**
مشخصات پنل‌های نصب‌شده به‌صورت امن در حافظه مرورگر شما (
`localStorage`
) ذخیره می‌شوند. در مراجعه‌های بعدی، می‌توانید تنها با کلیک روی گزینه 
**«⚡️ به‌روزرسانی سریع»**، بدون نیاز به ورود مجدد API Token یا Account ID، ورکر خود را ارتقا دهید.**
**3️⃣ **استقرار خودکار و  شفاف پروکسی (CI/CD via GitHub Actions):**
کد پروکسی ارتباطی با Cloudflare API به‌طور کامل متن‌باز بوده و فرایند استقرار آن از طریق 
**GitHub Actions**
 پیاده‌سازی شده است. این پروکسی صرفاً به مسیرهای ضروری نصب‌کننده محدود شده است تا شفافیت و امنیت ۱۰۰ درصدی تضمین شود.
***4️⃣***
 
**بهینه‌سازی کامل رابط کاربری (Cross-Platform UI/UX):**
* 
**پشتیبانی کامل از ویندوز:**
 رفع مشکلات چیدمان در مرورگرهای ویندوز (Chrome / Edge) و استفاده از فونت استاندارد 
**«وزیرمتن»**
 برای نمایش شفاف متون فارسی.
* 
**سازگاری با نمایشگرهای عریض:**
 اصلاح چیدمان صفحه در مانیتورهای بزرگ (1080p, 2K, 4K) و جلوگیری از پراکندگی کلیدها.
* 
**تجربه کاربری موبایل:**
 بهینه‌سازی ابعاد کلیدها و فرم‌ها طبق استانداردهای لمسی دستگاه‌های موبایل.
