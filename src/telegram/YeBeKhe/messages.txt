Nova Proxy
یک ابزار پروکسی محلی قدرتمند به نام NovaProxy است که برای عبور از فیلترینگ سنگین و سیستم‌های پیشرفته DPI طراحی شده.
• 
**Domain Fronting**
: از دید DPI همه ترافیک شبیه ارتباط با گوگل است
• 
**H2 Multiplexing**
: یک اتصال HTTP/2 پایدار برای همه درخواست‌ها
• 
**Request Batching**
: تجمیع درخواست‌ها در پنجره ۵ میلی‌ثانیه (حداکثر ۵۰ تا)
• 
**Response Caching**
: کش LRU با حجم ۵۰ مگابایت و TTL هوشمند
• 
**Auto-Failover**
: تشخیص خطا و تعویض خودکار IP
• 
**SNI Rotation**
: چرخش خودکار بین دامنه‌های 
[google.com](https://google.com/)
, 
[mail.google.com](https://mail.google.com/)
, 
[accounts.google.com](https://accounts.google.com/)
• 
**Scanner IP **
Google: پروب ۲۶ IP ثابت + IP های DNS با همروندی ۸ تایی
• 
**Speed Test**
: اندازه‌گیری سرعت واقعی دانلود
• 
**TUN**
 Mode: مدیریت کل ترافیک سیستم‌عامل بدون تنظیم دستی
• 
**Split Tunnel**
: مسیریابی بر اساس نام برنامه (allowlist)
• 
**LAN Sharing**
: اشتراک پروکسی در شبکه محلی
• 
**Smart Routing**
: سرویس‌های حساس گوگل (Gmail, Drive, Meet) مستقیم وصل می‌شوند
• 
**SNI Rewrite**
: بازنویسی خودکار SNI برای یوتیوب و دابل‌کلیک
• 
**A**
uto install Certificate: روی ویندوز، مک، لینوکس و فایرفاکس
این ابزار از مسیریابی هوشمند، کش و بچینگ درخواست‌ها پشتیبانی کرده
