**Rakhsh | رخش**
یه هسته‌ی شبکه که از صفر با Rust نوشته شده و برای ایجاد تونل بین سرور ایران و خارج، به‌صورت هم‌زمان روی چندین حامل مختلف کار می‌کنه.
حتی روی یک سرور هم می‌تونه نقش پروکسی و روتر رو ایفا کنه.
***🔹***
 
**ورودی‌ها:**
 ● SOCKS5
 ● HTTP
 ● Port Forwarding
 ● TUN
***🔹***
 
**خروجی‌ها:**
 ● Direct
 ● Tunnel
 ● Block
 ● SOCKS Chain
مسیریابی هم بر اساس Rule و فایل‌های Geo انجام می‌شه.
***🔹***
 
**حامل‌های ارتباطی (Carriers):**
 ● TCP
 ● TLS
 ● WebSocket (WS / WSS)
 ● QUIC (v1 / v2)
 ● KCP
 ● FakeTCP
 ● L2TCP
 ● ICMP
 ● Spoof
از طریق Shabdiz هم از این موارد پشتیبانی می‌کنه:
 ● GRE (IPv4 / IPv6)
 ● ESP
 ● IPIP
 ● 6to4
 ● EtherIP
 ● L2TPv3
 ● MPLS-in-IP (Layer 2)
 ● UDP / TCP
***⚡️***
 
**قابلیت‌های مهم:**
 ● چندین لاین ارتباطی به‌صورت هم‌زمان روی حامل‌های مختلف
 ● در صورت قطع شدن یکی از لاین‌ها، ترافیک از لاین‌های باقی‌مونده ادامه پیدا می‌کنه.
 ● با قابلیت Stream Resume، استریم‌ها هم قطع نمی‌شن و روی لاین دیگه ادامه پیدا می‌کنن.
 ● رمزنگاری با Noise IKpsk2 و AES-256-GCM

**Shabdiz | شبدیز**
شبدیز هسته‌ی انتقال دیتاگرامه که رخش روی اون سوار شده.
این پروژه هم از صفر با Rust نوشته شده، کاملاً مستقله و می‌تونید ازش در پروژه‌های مختلف استفاده کنید.
***🔹***
 
**ویژگی‌های فنی:**
 ● انتقال دیتاگرام بدون صف؛ یعنی اگر پکتی گم بشه، فقط همون پکت از دست می‌ره و بقیه منتظرش نمی‌مونن (بدون Head-of-Line Blocking).
 ● استریم مطمئن (Reliable Stream) فقط برای ترافیکی که واقعاً بهش نیاز داره.
 ● اندازه‌گیری دقیق Packet Loss با شمارنده‌ی هر پکت، بدون نیاز به Probe.
 ● کنترل شکل و الگوی ترافیک، نه صرفاً سرعت اون.
 ● Traffic Pacing در سطح کرنل با استفاده از SO_TXTIME
 ● مدیریت MTU
 ● شناسایی و انتخاب خودکار مسیر
 ● رمزنگاری مستقل هر پکت با Noise IKpsk2 و AES-256-GCM
***🔹***
 
**حامل‌های ارتباطی:**
 ● GRE (IPv4 / IPv6)
 ● ESP
 ● IPIP
 ● 6to4
 ● Layer 2
 ● UDP
 ● TCP
 ● پشتیبانی از شماره پروتکل IP دلخواه
از جمله:
EtherIP، L2TPv3، MPLS-in-IP و موارد مشابه.
***💡***
