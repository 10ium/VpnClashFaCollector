### 🕒 2026-06-26 13:56:41 UTC
نهان 2.9.1
## [2.9.1] - ۱۴۰۵-۰۴-۰۴ (2026-06-26)
### اضافه شده (Added)
- 
**مسیریابی آی‌پی رله به‌ازای هر کانفیگ تروجان**
: نودهای تروجان اکنون از طریق پیلود مسیر وب‌ساکت، آی‌پی رله تعیین‌شده خود را دریافت می‌کنند (مانند VLESS).
- 
**زنجیره بازگشت سه‌گانه استخراج شاخص رله**
: پارامتر کوئری → بخش عددی مسیر → پیلود JSON باینری.
- 
**محدودیت اتصال دستگاه برای هر کاربر (connLimit)**
: محدود کردن اتصالات همزمان هر مشترک.
- 
**سیستم کلید API پنل**
: احراز هویت امن اتصال نود به پنل.
- 
**فرم‌های کاربر سازگار با موبایل**
: طرح‌بندی واکنش‌گرا بهبودیافته برای فرم‌های افزودن/ویرایش.
### رفع شده (Fixed)
- 
**رفع خطای افست هدر تروجان**
 (hPos+2 → hPos+4): اتصالات تروجان ۲ بایت اول پس از فیلد پورت را حذف می‌کردند.
- 
**رفع رمز عبور تروجان**
: رمز عبور به‌جای configUuid تولیدشده از UUID خام کاربر استفاده می‌کند.
- 
**ثبت هش SHA224**
: افزودن هش SHA224 در configRegistry برای جستجوی تروجان.
- 
**حذف فیلدهای اضافی**
: حذف میزبان‌های نگهداری و کلید API همگام‌سازی از بخش آدرس پروکسی پیشرفته.
### بهبود یافته (Improved)
- 
**مسیریابی آی‌پی رله تروجان**
: استفاده از قالب پیلود JSON باینری مسیر وب‌ساکت مانند VLESS.
- 
** آدرس رله**
: استفاده از getEffectivePips با پشتیبانی NAT64 برای هر دو پروتکل.
- 
**متغیر reqPath**
: افزودن به buildYamlProfile برای تولید مسیر یکپارچه.
نکته مهم: کسایی که به 2.9.0 آپدیت کرده بودن و ارور 1101 گرفته بودن، اگه کاربر داشتن نمیخوان ادرس جدید بسازن:
1. ورکر رو پاک کنن  
2.با همون اسم دوباره بسازن 
3.کد ورکر جدید رو وارد ورکر کنن، 
4.از توی binding  دیتابیس قبلیو که ساختید وصل کنید ، جدید نسازید پنل مجدد با همون ادرس کار میکنه
