### 🕒 2026-08-02 10:13:39 UTC
**نتیجه بررسی ایمن بودن برنامه AetherST v1.4.0**
برنامه AetherST کاملا امن هستش.
**در مورد پرمیشن پایین که ممکنه آنتی‌ویروس‌ها بخاطرش فلگ بزنن:**
DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
این پرمیشن مربوط به اندروید ۱۳ یعنی API 33 میشه که برای جبران یک ضعف امنیتی بکار میره.
قبل از API 33 هر اپی می‌تونست به رسیور یک برنامه دیگه پیام ارسال کنه و این یک ضعف امنیتی بود. این پرمیشن این ضعف امنیتی رو برطرف می‌کنه.
**در مورد اخطار وایت دی‌ان‌اس:**
وایت dns یه سیستم ارزیابی راه‌انداخته و فقط اعلام کرده که دیگه یه سری از نسخه‌ها رو ارزیابی نمی‌کنه، یعنی به لحاظ امنیتی بررسی نمی‌کنه.
پس اگر در آینده یه ورژن از این برنامه‌ها آلوده باشه دیگه وایت dns مسئولیتی در این مورد نداره.
وایت dns حتی هسته اصلی Aether رو ارزیابی نمی‌کنه اما گفته نسخه ویندوزی متین سن‌پای که از همون هسته استفاده می‌کنه رو ارزیابی، یعنی تایید می‌کنه.
در نتیجه وایت dns اصلا نگفته اینها ناامن هستن.
بعضی آنتی‌ویروس‌ها ممکنه یه فلگ بزنن بخاطر روش‌های ضد DPI که برنامه برای دور زدن فیلترینگ اعمال می‌کنه.
**نکته:**
 هیچ یک از این فیلترشکن‌ها برای انجام کارهای سیاسی، خبرنگاری و حساس نیست. دقیقا همان‌طور که سایفون در صفحه رسمی خودش همین موضوع رو برای برنامه خودش گفته.
**پس این ابزارها برای عبور از سیستم فیلترینگ هستن، نه برای ناشناس ماندن.**

**AetherST Tunnel v1.4.0**
**نسخه 1.3.0 باگ داشت و وصل نمی‌شد، حتما آپدیت کنید.**
 
**اگه از قبل نصب داشتید کلیر دیتا کنید.**
***✨***
 
**ویژگی‌های اصلی:**
• اتصال مخفی و مقاوم در برابر DPI و تشخیص پروتکل
• پشتیبانی از پروتکل‌های پیشرفته: MASQUE (HTTP/3 و HTTP/2)، WireGuard، Gool (WG-in-WG) و Cloudflare Zero Trust
• اسکن هوشمند گیت‌وی با اعتبارسنجی لحظه‌ای قبل از اتصال
• عملکرد بالا و تأخیر کم با موتور بومی C (HEV SOCKS5)
• رابط کاربری مدرن و تمیز (الهام‌گرفته از iOS) با Jetpack Compose
• ابزارهای تشخیصی، لاگ لحظه‌ای و پریست‌های آماده پروتکل.
***📡***
 
**پروتکل‌ها:**
*مسک:*
 ترافیک شبیه مرور وب معمولی → عبور عالی از فیلترینگ
*وایرگارد:*
 سرعت بالا + مصرف باتری کم
*گول:*
