تغییرات نسخه جدید 
قابلیت فیلتر کردن HTML DOM به ادبلوک اضافه شده و حالا این کار در سطح شبکه انجام می‌شه.
ادبلوک حالا می‌تونه به‌صورت لحظه‌ای المان‌های جدیدی که داخل صفحات وب لود می‌شن رو هم فیلتر کنه.
پشتیبانی از قوانین (Rules) uBlock در موتور ادبلوک خیلی گسترده‌تر شده.
مشکل کرش کردن ادبلوک هنگام استفاده از Cronet برطرف شده.
لیست دور زدن HTTP Proxy (از آپدیت‌های Starifly) اضافه شده.
امکان تعریف DNS سفارشی برای دامنه‌ها مثل Husi اضافه شده، با این تفاوت که حالا می‌شه برای یک دامنه چندین IP مختلف تعریف کرد.
باگ گیر کردن دکمه اتصال (Connect) در جای اشتباه در بعضی شرایط برطرف شده.
از این به بعد برنامه فایل DNS مربوط به Sing-box رو با فرمت نسخه 1.13.x تولید می‌کنه، نه نسخه 1.12.x.
منابع uBlock با منابع رسمی پروژه Brave adblock-resources جایگزین شدن.
توی صفحه اطلاعات نسخه، ورژن ماژول‌های جانبی که برنامه ازشون استفاده می‌کنه هم نمایش داده می‌شه.
تمام تغییرات Starifly تا نسخه 1.4.2-mod-15 (به‌جز تغییرات مربوط به تم‌ها) به برنامه اضافه شده.
