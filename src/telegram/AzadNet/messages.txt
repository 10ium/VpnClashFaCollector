 آموزش گام‌به‌گام راه‌اندازی پنل Zeus Cloudflare
اگر قصد دارید پنل Zeus را راه‌اندازی کنید، مراحل زیر را به‌ترتیب انجام دهید:
***1️⃣***
 ساخت حساب کاربری Cloudflare
ابتدا وارد سایت Cloudflare شوید و با یک ایمیل معتبر ثبت‌نام کنید.
***🔗***
 
[https://dash.cloudflare.com/profile/api-tokens](https://dash.cloudflare.com/profile/api-tokens)
نکته: پس از ثبت‌نام، حتماً ایمیل خود را تأیید (Verify) کنید.
***2️⃣***
 ورود به بخش API Token
بعد از ورود به حساب کاربری:
از بخش Manage Account وارد قسمت Account API Tokens شوید.
روی گزینه Create Custom Token کلیک کنید.
یک نام دلخواه برای توکن خود انتخاب کنید.
***3️⃣***
 تعیین دسترسی‌های موردنیاز
در بخش جستجو، نام هر مورد را وارد کرده و سطح دسترسی Edit یا Read را مطابق لیست زیر انتخاب کنید:
***✅***
 Workers Scripts → Edit
***✅***
 Workers KV Storage → Edit
***✅***
 D1 → Edit
***✅***
 Account Settings → Read
***4️⃣***
 ساخت و کپی کردن توکن
پس از اعمال دسترسی‌ها، روی Confirm کلیک کنید.
***⚠️***
 قبل از خروج از صفحه، حتماً API Token را کپی کنید.
بعد از بستن این صفحه، امکان مشاهده مجدد توکن وجود ندارد.
***5️⃣***
 ساخت پنل Zeus
وارد ربات 
[@EzCfWBot](https://t.me/EzCfWBot)
 شوید.
ربات را Start کنید.
گزینه ساخت پنل را انتخاب کنید.
API Token کپی‌شده را برای ربات ارسال کنید.
در پایان، نوع پنل موردنظر خود را انتخاب کنید تا فرآیند ساخت پنل تکمیل شود.
***🎉***
 تبریک! پنل Zeus شما با موفقیت راه‌اندازی خواهد شد.
