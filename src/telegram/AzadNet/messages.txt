***🔗***
 
[https://dash.cloudflare.com/profile/api-tokens](https://dash.cloudflare.com/profile/api-tokens)
نکته: پس از ثبت‌نام، حتماً ایمیل خود را تأیید (Verify) کنید.
***2️⃣***
 ورود به بخش API Token
بعد از ورود به حساب کاربری:
از بخش Manage Account وارد قسمت Account API Tokens شوید.
روی گزینه Create Custom Token کلیک کنید.
یک نام دلخواه برای توکن خود انتخاب کنید.
***3️⃣***
 تعیین دسترسی‌های موردنیاز

***✅***
 Workers Scripts → Edit
***✅***
 Workers KV Storage → Edit
***✅***
 D1 → Edit
***✅***
 Account Settings → Read
***4️⃣***
 ساخت و کپی کردن توکن
پس از اعمال دسترسی‌ها، روی Confirm کلیک کنید.

 قبل از خروج از صفحه، حتماً API Token را کپی کنید.
بعد از بستن این صفحه، امکان مشاهده مجدد توکن وجود ندارد.
