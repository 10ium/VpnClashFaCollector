**یکی از روش‌های وصل شدن با اینترنت ضعیف، استفاده از کانفیگ بصورت پروکسی هس**
در این آموزش از دو برنامه v2rayNG و npv میتونیم استفاده کنیم:
**مراحل تبدیل V2RayNG به پروکسی**
***1️⃣***
 وارد برنامه بشید → سه خط بالا (منو) → Settings
***2️⃣***
 گزینه‌های زیر رو تنظیم کنید:
Mode → Proxy Only
Local Proxy Port → 10808
***3️⃣***
 برگردید → دوباره منو → Per-app settings
گزینه Enable per-app رو روشن کنید
تیک تمام برنامه‌ها رو بردارید 
***4️⃣***
 VPN رو روشن کنید
***5️⃣***
 وارد تلگرام بشید → Settings → Proxy → Add Proxy
تنظیمات:
Type → SOCKS5
Server → 
[127.0.0.1](http://127.0.0.1/)
Port → 10808
Username / Password → خالی
 ذخیره کنید
**مراحل تبدیل NPV TUNNEL به پروکسی**
***1️⃣***
 وارد برنامه بشید → پایین صفحه More (سه نقطه) → Settings
***2️⃣***
 گزینه:
Local Proxy Port → 10808
***3️⃣***
 دوباره برید More → Per-app proxy
گزینه Enable Per App Proxy روشن
وارد Disallowed Apps بشید و همه برنامه‌ها رو تیک بزنید (حتی تلگرام) 
***4️⃣***
 VPN رو روشن کنید
***5️⃣***
 برید تلگرام → Add Proxy
تنظیمات:
Type → SOCKS5
Server → 
[127.0.0.1](http://127.0.0.1/)
Port → 10808
Username / Password → خالی
 ذخیره کنید
