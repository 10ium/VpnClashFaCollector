### 🕒 2026-08-23 15:06:35 UTC
آموزش وارد کردن فایل بکاپ در 
[Exclave](https://github.com/ExclaveNetwork/Exclave/releases/tag/0.17.53)
 و 
[Husi](https://github.com/xchacha20-poly1305/husi/releases/tag/v1.4.5)
***🔹***
 کلاینت Exclave
1. ابتدا روی فایل بکاپ داخل تلگرام سه‌نقطه ⋮ رو بزنید.
2. گزینه Save to Downloads رو انتخاب کنید تا فایل داخل پوشه Downloads گوشی ذخیره بشه.
3. حالا وارد کلاینت Exclave بشید.
4. روی سه‌خط ☰ بزنید و وارد بخش Tools بشید.
5. گزینه Backup رو انتخاب کنید.
6. روی آخرین گزینه یعنی Import from file بزنید.
7. وارد پوشه Downloads بشید و فایل بکاپی که ذخیره کردید رو انتخاب کنید.
***🔹***
 کلاینت Husi
1. ابتدا روی فایل بکاپ داخل تلگرام سه‌نقطه ⋮ رو بزنید.
2. گزینه Save to Downloads رو بزنید تا فایل داخل پوشه Downloads گوشی ذخیره بشه.
3. وارد کلاینت Husi بشید.
4. از پایین صفحه، گزینه اول یعنی Settings رو انتخاب کنید.
5. وارد بخش Backup بشید.
6. روی Import from file بزنید.
7. وارد پوشه Downloads بشید و آخرین فایل بکاپ رو انتخاب کنید.
