**اسکیل rust-anything اپت رو تیکه‌تیکه به Rust بازنویسی می‌کنه و ثابت می‌کنه هیچی خراب نشده**
rust-anything یه ابزار و اسکیل کلاد کده که اپ TypeScript و Python و C و Go و Ruby و Java رو قدم‌به‌قدم به Rust خالص می‌بره.
طرز کارش این شکلیه که اول رفتار نسخه اصلی رو روی هزاران ورودی ضبط می‌کنه، حتی کیس‌های لبه‌ای مثل ایموجی و سرریز عددی. یه باینری Rust می‌ذاره جلو و هر تیکه‌ای که هنوز پورت نشده برمی‌گرده به نسخه اصلی، یعنی اپ از روز اول کار می‌کنه. هر واحد که پورت شد، همه کیس‌ها روش ری‌پلی می‌شن و باید صددرصد یکی باشن. وقتی دیگه فالبکی نموند، کد قدیمی حذف می‌شه.
سازنده‌ش می‌گه ۳۸٬۲۵۱ کیس ضبط‌شده با صفر مغایرت ری‌پلی شدن و توی حالت فقط سرعت، جست‌وجو توی Node بیست برابر سریع‌تر شده. نصبش یه دستوره و لایسنسش MITه. نسخه ۲ش هم اومده که باهاش Prettier رو پورت کردن و ۱۹ برابر سریع‌ترش کردن.

### 🕒 2026-11-20 13:01:02 UTC
**کلادفلر مدل Clairic رو منتشر کرده که خروجیش رایگانه**
Clairic یه مدل استخراج داده‌ست؛ متن و PDF و عکس رو می‌دی و اطلاعات ساخت‌یافته ازش درمیاره. مثلاً متن آگهی استخدام رو می‌دی و می‌گی مهارت‌های ضروری و ترجیحی و سابقه و حقوق رو دربیار، یا عکس فاکتور رو می‌دی و مبلغ و تاریخ رو می‌گیری. فرقش با Jev اینه که Jev تصمیم‌گیری و امتیازدهی می‌کنه، این یکی فقط داده استخراج می‌کنه.
طرز کارش این شکلیه که ساختار خروجی رو هم خودت تعیین می‌کنی؛ مثلاً می‌گی فقط JSON بده و خروجی رو مستقیم می‌بری توی دیتابیس. برای هر فیلد هم امتیاز اطمینان می‌ده، یعنی خروجی‌های کم‌اطمینان رو جدا می‌کنی برای بررسی انسانی و مطمئن‌ها رو اتوماتیک جلو می‌بری.
«خروجی رایگان» یعنی مدل توکن خروجی تولید می‌کنه ولی کلادفلر پولش رو نمی‌گیره؛ فقط ورودی حساب می‌شه، فعلاً ۱۰ سنت برای هر یک میلیون توکن. هر دو نسخه‌ش هم اوپن ویتن و می‌تونید روی زیرساخت خودتون اجراش کنید. نویسنده‌ش می‌گه برای استخراج اطلاعات از متن‌های فارسی هم گزینه‌ی خوبیه.
