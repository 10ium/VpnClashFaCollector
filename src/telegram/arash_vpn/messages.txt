راهنمای  اتصال به اینترنت آزاد با HTTP Injector (آیفون)
گام اول: نصب برنامه
وارد App Store بشید، برنامه HTTP Injector رو جستجو کنید و اون رو دانلود کنید (لوگوی برنامه یک موشک سفید در پس‌زمینه آبی است).
گام دوم: تنظیم نوع اتصال (Tunnel Type)
برنامه رو باز کنید.
در صفحه اصلی، روی بخش Tunnel Type (آیکون فلش/پیکان) ضربه بزنید.
در لیستی که باز میشه، نوع تونل رو روی DNSTT تنظیم کنید.
دکمه Save (ذخیره) رو بزنید تا به صفحه اصلی برگردید.
گام سوم: وارد کردن نام کاربری و رمز عبور
در صفحه اصلی، روی آیکون چرخ‌دنده (Settings) در گوشه صفحه ضربه بزنید.
وارد بخش SSH/SOCKS Settings بشید.
اطلاعات زیر رو با دقت و بدون فاصله (Space) اضافه وارد کنید:
Username (نام کاربری): arash
Password (رمز عبور): arash
به منوی قبلی برگردید.
گام چهارم: تنظیمات سرور و DNS (بسیار مهم)
در همون صفحه تنظیمات، این بار وارد بخش DNSTT Settings بشید.
در قسمت Name Server (یا NS)، آدرس زیر رو دقیقاً به همین شکل وارد کنید (دقت کنید که کلمه http:// رو ننویسید):
[t1.arash.email](http://t1.arash.email/)
در قسمت Public Key، این کد طولانی رو کپی و جای‌گذاری کنید:
eef1b34767c4615cfb576829cdfc61fd149b29de02208d08926d3dc2bd2a5859
در قسمت DNS Resolver، باید آدرس یک سرور دی‌ان‌اس عمومی رو وارد کنید. پیشنهاد ما این آدرس است:
[93.118.114.23:53](http://93.118.114.23:53/)
کار تمام است! به صفحه اصلی برنامه برگردید.
گام پنجم: روشن کردن فیلترشکن
حالا فقط کافیست روی دکمه بزرگ Start در پایین یا وسط صفحه ضربه بزنید.
اگر اولین بار است که از برنامه استفاده می‌کنید، آیفون از شما اجازه می‌خواد که پروفایل VPN رو بسازه. روی Allow کلیک کنید و رمز گوشی (یا Face ID) رو بزنید.
چند ثانیه صبر کنید تا کلمه Connected روی صفحه ظاهر بشه.
***💡***
 نکته مهم برای اتصال بهتر: این روش برای عبور از شدیدترین محدودیت‌ها طراحی شده. اگر متصل نشد یا سرعت اولیه کم بود، یک بار گوشی رو روی حالت پرواز (Airplane Mode) بذارید، چند ثانیه صبر کنید، از حالت پرواز خارج بشید و دوباره دکمه Start رو بزنید.
