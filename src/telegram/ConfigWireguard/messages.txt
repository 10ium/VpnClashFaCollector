[پروژه](https://github.com/mehdi-hexing/CF-Workers-CheckProxyIP)
 و کاربرد آن
این یک پروژه متن‌باز برای بررسی و تست پراکسی آی‌پی‌های کلودفلر است. این ابزار به‌طور ویژه برای کاربرانی که از پنل‌هایی مثل 
[BPB](https://github.com/bia-pain-bache/BPB-Worker-Panel)
 و 
[Cfnew](https://github.com/byJoey/cfnew)
 و موارد مشابه استفاده می‌کنند، طراحی شده تا کیفیت اتصال خود را بهینه‌سازی کنند.
نحوه عملکرد
این پروژه از دو لایه API استفاده می‌کند:
آدرس API های اختصاصی: استفاده از رابط‌هایی که از قبل در بستر کلودفلر برای این کار تعریف شده‌اند.
منطق چک کردن مستقل: یک سیستم بررسی داخلی که فارغ از API ها، سلامت و کارایی آی‌پی‌ها را به صورت مجزا تست می‌کند.
ویژگی‌های کاربردی:
یافتن پراکسی آی‌پی‌های جدید :
اگر یک پراکسی آی‌پی دارید که از کار افتاده  می‌توانید رنج آن را در باکس دوم سایت به این صورت وارد کنید :
`1.2.3.0/24`
با این کار، سیستم در آن محدوده جستجو کرده و آی‌پی‌های سالم و جایگزین را برای شما پیدا می‌کند.
مدیریت آی‌پی‌های پشت دامنه:
اگر دامنه‌ای دارید که چندین آی‌پی پشت آن قرار گرفته، می‌توانید دامنه را در باکس اول وارد کنید تا آی‌پی‌های از کار افتاده را شناسایی و حذف کنید.
همچنین اگر دامنه‌ای پیدا کردید که پراکسی آی‌پی‌های باکیفیتی دارد، می‌توانید با وارد کردن آن در سایت، لیست تمامی آی‌پی‌های سالم آن را استخراج کنید.
منبع رایگان و جهانی:
این پروژه دارای یک دیتابیس داخلی و رایگان است که به کاربر اجازه می‌دهد به سادگی، پراکسی آی‌پی‌های مورد نیاز خود را از هر کشور دلخواهی انتخاب و دریافت کند.
سنجش ریسک آی‌پی (IP Risk):
این ابزار به سرویس Scamalytics مجهز شده است تا «سطح ریسک» یا سابقه آی‌پی را نمایش دهد.
ریسک آی‌پی چیست؟
در واقع نمره‌ای است که بر اساس سابقه فعالیت آن آی‌پی تعیین می‌شود. برای مثال، اگر از یک آی‌پی برای حملات سایبری یا فعالیت‌های مخرب استفاده شده باشد، نمره ریسک آن بالا می‌رود (مثلاً 80 از 100). کاربران می‌توانند با این ویژگی، آی‌پی‌هایی با کمترین ریسک و بالاترین کیفیت را انتخاب کنند.
