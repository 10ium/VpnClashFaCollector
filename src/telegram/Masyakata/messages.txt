برای وصل کردن سایفون به مستر دی‌ان‌اس (Master DNS) با استفاده از قابلیت فرگمنت (Fragment)، باید بدانید که فرگمنت یک لایه فراتر از دی‌ان‌اس ساده است. در واقع شما یک «پروکسی داخلی» می‌سازید که ترافیک سایفون را تکه‌تکه (Fragment) می‌کند تا از سد فیلترینگ عبور کند.
در اینجا راهنمای دقیق و گام‌به‌گام این کار آورده شده است:
***📚***
 مرحله ۱: تنظیم کد در Master DNS
شما نمی‌توانید فقط بخش DNS را وارد کنید؛ برای اینکه فرگمنت کار کند، باید ساختار کامل (شامل ورودی و خروجی) را داشته باشید. 
در برنامه Master DNS، در قسمت تنظیمات سفارشی (Custom JSON)، این کد دقیق را کپی و جایگذاری کنید:
{
  "inbounds": [
    {
      "listen": "
[127.0.0.1](http://127.0.0.1/)
",
      "port": 10808,
      "protocol": "socks",
      "settings": {
        "auth": "noauth",
        "udp": true
      },
      "tag": "socks-in"
    }
  ],
  "outbounds": [
    {
      "protocol": "freedom",
      "settings": {
        "fragment": {
          "packets": "tlshello",
          "length": "100-200",
          "interval": "1-1"
        }
      },
      "tag": "fragment-out"
    }
  ],
  "dns": {
    "servers": [
      "
[1.1.1.1](http://1.1.1.1/)
",
      "
[8.8.8.8](http://8.8.8.8/)
"
    ]
  }
}
نکته: بعد از ذخیره، حتماً دکمه اتصال (Start/Connect) را در Master DNS بزنید تا این پروکسی روی پورت 10808 در گوشی شما فعال شود.
---
***📚***
 مرحله ۲: تنظیمات در برنامه سایفون (Psiphon)
حالا باید به سایفون بگویید که مستقیم به اینترنت وصل نشود، بلکه ترافیکش را به Master DNS بفرستد:
1. برنامه Psiphon را باز کنید.
2. به بخش Options (تنظیمات) بروید.
3. روی More Options (تنظیمات بیشتر) بزنید.
4. در بخش Proxy Settings (تنظیمات پروکسی)، تیک گزینه Connect through an HTTP Proxy را بزنید. (در برخی نسخه‌ها باید گزینه Use system network settings را غیرفعال کنید و دستی تنظیم کنید).
5. گزینه Use the following settings را انتخاب کنید:
• Host Address: 
[127.0.0.1](http://127.0.0.1/)
• Port: 10808
6. اگر گزینه انتخاب نوع پروکسی وجود داشت، آن را روی SOCKS بگذارید (اگر فقط HTTP بود، همان را تست کنید اما SOCKS برای کد بالا بهتر است).
7. به صفحه اصلی سایفون برگردید و Start را بزنید.
