**SlipNet**
**اعمال این موارد در slipnet خروجی بهتری میده:**
1. در بخش تنظیمات گزینه
Auto reconnect
رو فعال کنید تا درصورت قطعی کانفیگ خودکار متصل بشه.
2. داخل تنظیمات SlipNet برید اسکرول کنید به پایین و گزینه
max channels 28 - 32
3. در بخش تنظیمات 
Split Tunneling 
گزینه
Enable split tunneling
رو فعال کنید
و بعد مود رو بزارید روی 
Only
حالا در بخش
Selecte Apps
اپلیکشن های خودتون رو انتخاب کنید
**اکیدا توصیه میکنم فقط تلگرام رو استفاده کنه تا کل ترافیک موبایل به تلگرام داده بشه**
4. در تنظیمات اپلیکشن بخش 
DNS -
        -> Remote Dns Server
ضربه بزنید بعدش روی گزینه
Custome
و بعد دوتا دی ان اس زیر را در بخشهای
Primary DNS Server : - 
[78.157.42.101](http://78.157.42.101/)

[78.157.42.100](http://78.157.42.100/)
وارد نمایید

**2.3**

یکم اسکرول کنید به پایین
DNS Query Size
رو بین 50 یا 60 بزارید سرعت میاد پایین تر ولی پایدار تر میشه اتصالتون
