**🚀 ۱۰ ترفند کاربردی V2Ray و VPN در ویندوز**
***🔹***
 ۱. System Proxy چیکار می‌کنه؟
وقتی گزینه Set System Proxy رو می‌زنید، ویندوز یک آدرس مثل "
[127.0.0.1](http://127.0.0.1/)
" و یک پورت رو به‌عنوان Proxy ثبت می‌کنه. V2Ray روی همون پورت منتظر می‌مونه و برنامه‌هایی که از System Proxy استفاده می‌کنن، از تونل عبور می‌کنن.
***🔹***
 ۲. فقط یک برنامه رو از VPN رد کنیم
لازم نیست کل ویندوز VPN باشه. مثلاً می‌تونید داخل Telegram یا Firefox، آدرس "
[127.0.0.1](http://127.0.0.1/)
" و پورت V2Ray رو وارد کنید تا فقط همون برنامه از پروکسی استفاده کنه.
***🔹***
 ۳. برنامه‌ای که Proxy نداره؟
بعضی بازی‌ها و برنامه‌ها تنظیمات Proxy ندارن. ابزارهایی مثل Proxifier می‌تونن کمک کنن؛ برای هر برنامه Rule می‌سازید تا فقط همون برنامه از V2Ray عبور کنه.
***🔹***
 ۴. سایت‌های ایرانی مستقیم، خارجی‌ها با VPN 
***🇮🇷***
***🌍***
با Routing می‌تونید مشخص کنید چه ترافیکی از VPN عبور کنه و چه ترافیکی مستقیم بره؛ مثلاً سایت‌های داخلی مستقیم و سایت‌های خارجی از VPN.
***🔹***
 ۵. جلوگیری از اتصال ناخواسته مستقیم 
***🔒***
اگر فقط از System Proxy استفاده کنید و VPN قطع بشه، بعضی برنامه‌ها ممکنه دوباره مستقیم به اینترنت وصل بشن. برای بعضی سناریوها، استفاده از Proxy مستقیم داخل خود برنامه می‌تونه جلوی این اتفاق رو بگیره.
***🔹***
 ۶. TUN Mode 
***🛡️***
بعضی برنامه‌ها اصلاً Proxy رو پشتیبانی نمی‌کنن. TUN Mode با ساخت یک رابط شبکه مجازی، ترافیک رو در سطح شبکه هدایت می‌کنه؛ بنابراین لازم نیست تک‌تک برنامه‌ها رو تنظیم کنید.
***🔹***
 ۷. Proxy برای Git، Pip و NPM 
***💻***
ابزارهایی مثل Git، Pip و NPM همیشه از Proxy ویندوز استفاده نمی‌کنن. می‌تونید Proxy رو مستقیماً برای خود این ابزارها یا محیط ترمینال تنظیم کنید.
***🔹***
 ۸. آپدیت خودکار Subscription 
***🔄***
اگه از Subscription استفاده می‌کنید، می‌تونید یک بازه زمانی برای آپدیت خودکار تعیین کنید تا لازم نباشه هر بار لینک کانفیگ‌ها رو دستی به‌روزرسانی کنید.
***🔹***
 ۹. Kill Switch 
***⚠️***
اگر VPN قطع بشه، ممکنه ترافیک دوباره از مسیر مستقیم خارج بشه. بعضی کلاینت‌ها در TUN Mode گزینه‌هایی مثل Strict Route دارن که می‌تونن جلوی این اتفاق رو بگیرن؛ البته حتماً عملکردش رو بعد از فعال‌سازی تست کنید.
***🔹***
 ۱۰. اشتراک‌گذاری VPN با دستگاه‌های دیگه 
***🏠***
می‌خواید VPN کامپیوتر رو روی دستگاه دیگه‌ای هم استفاده کنید؟
با فعال کردن Allow Connection for LAN می‌تونید Proxy V2Ray رو در شبکه داخلی در اختیار دستگاه‌های دیگه بذارید. بعد IP کامپیوتر و پورت Proxy رو روی دستگاه مقصد وارد می‌کنید.
