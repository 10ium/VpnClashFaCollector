یعنی چی؟

**انتهای پست زیر لینک چند‌تاشون هست:**
[https://t.me/DigiHubAI/46109](https://t.me/DigiHubAI/46109)
***🔹***
 نحوه کار :
با refreshToken حساب Cline احراز هویت میکنی، ورکر درخواستت رو دریافت میکنه، به مدل رایگان Cline وصل میشه و پاسخ رو با فرمت OpenAI API برمیگردونه.
***🔹***
 پشتیبانی از چند حساب :
می‌تونی چند حساب Cline اضافه کنی تا در صورت رسیدن یک حساب به لیمیت، درخواست‌ها از حساب‌های دیگه استفاده کنن.
***❌***
این پروژه برای استفاده از مدل‌های رایگان ارائه‌شده توسط Cline طراحی شده، بنابراین مدل‌ها و محدودیت‌ها ممکنه با تغییرات Cline تغییر کنن.
