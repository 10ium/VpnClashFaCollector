**🌐8 ابزار برای بررسی و کنترل اتصالات اینترنت برنامه‌ها**
 :
بعضی برنامه‌ها در پس‌زمینه به سرورها، سرویس‌های تحلیلی و Trackerها متصل میشن. با این ابزارها میتونید اتصالات شبکه رو بررسی کنید و دسترسی‌ها رو محدود کنید.
***📱***
 اندروید :
***1️⃣***
Rethink DNS :
ثبت اتصالات هر برنامه، نمایش آیپی مقصد و گزارش DNS، مسدودسازی برنامه‌ها و فیلترکردن تبلیغات و Trackerها.
***🔗***
 
[https://rethinkdns.com/app](https://rethinkdns.com/app)
***2️⃣***
TrackerControl :
نمایش شرکت‌ها و سرویس‌های ردیابی مورد استفاده اپ‌ها، بررسی مقصدهای شبکه و مسدودسازی Trackerها.
***🔗***
 
[https://trackercontrol.org](https://trackercontrol.org/)
***3️⃣***
NetGuard :
برای قطع یا محدودکردن اینترنت هر برنامه روی وایفای و دیتای موبایل.
***🔗***
 
[https://netguard.me/](https://netguard.me/)
***🖥️***
ویندوز:
***4️⃣***
Portmaster :
نمایش فعالیت شبکه برنامه‌ها و تعریف قوانین برای کنترل اتصال به مقصدهای مشخص.
***🔗***
 
[https://safing.io/portmaster](https://safing.io/portmaster)
***5️⃣***
TCPView :
ابزار رایگان مایکروسافت برای مشاهده اتصال‌های TCP و UDP، آدرس آیپی و پورت مقصد و فرایندی که اتصال رو ایجاد کرده. برای بررسی سریع اتصالاته، نه جایگزین یک فایروال کامل.
***🔗***
 
[https://learn.microsoft.com/en-us/sysinternals/downloads/tcpview](https://learn.microsoft.com/en-us/sysinternals/downloads/tcpview)
***6️⃣***
GlassWire :
نمایش مصرف داده، تاریخچه فعالیت شبکه و میزبان‌هایی که برنامه‌ها باهاشون ارتباط دارن.
***🔗***
 
[https://www.glasswire.com/](https://www.glasswire.com/)
***🐧***
 لینوکس‌ :
***7️⃣***
OpenSnitch :
هنگام تلاش برنامه‌ها برای اتصال خروجی، امکان بررسی و تعیین قانون اجازه یا مسدودسازی رو فراهم می‌کنه. اپن سورسه و مناسب کاربران فنی.
***🔗***
 
[https://opensnitch.org](https://opensnitch.org/)
***🍎***
 مک:
***8️⃣***
 LuLu :
فایروال رایگان و متن‌باز macOS که اتصال‌های خروجی برنامه‌ها رو بررسی می‌
کنه و اجازه میده ارتباطات ناشناخته یا ناخواسته رو مسدود کنی.
***🔗***
 
[https://objective-see.org/products/lulu.html](https://objective-see.org/products/lulu.html)
