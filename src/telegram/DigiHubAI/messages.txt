**معرفی کلاینت FoxyVPN :**
این کلاینت یک پروژه اپن‌سورس و کلاینت غیررسمی Firefox VPN برای اندرویده که امکان استفاده از VPN فایرفاکس را برای 
**کل دستگاه**
 فراهم میکنه.
***🔹***
این کلاینت از زیرساخت Mozilla Guardian استفاده میکنه، برخی از قابلیت‌ها:
• انتخاب سرور و لوکیشن
• Split Tunneling
• پشتیبانی از Private DNS و DNS رمزنگاری‌شده (DoH)
• امکان استفاده از Proxy در کنار VPN
• حالت Proxy-only
• نمایش IP و اطلاعات اتصال
• مشاهده لاگ‌ها
• پشتیبانی از تغییر تم
***🔸***
راه‌اندازیش بسیار ساده‌اس، ابتدا با ایمیلتون یک حساب رایگان فایرفاکس میسازید :
[https://accounts.firefox.com/signup](https://accounts.firefox.com/signup)
سپس اپ رو از گیتهاب نصب میکنید و با اطلاعات همون حساب وارد میشید. سهمیه‌اش هم دقیقا همون 50 گیگی هست که مرورگر فایرفاکس میده.
