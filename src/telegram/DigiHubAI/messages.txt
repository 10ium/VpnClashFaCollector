***🛡️***
**بررسی امنیت پروژه‌های GitHub :**
***1️⃣***
OpenSSF Scorecard :
امنیت کلی یک پروژه را بررسی میکنه و به مواردی مثل نحوه نگهداری پروژه، بررسی کد، تنظیمات گیت‌هاب و امنیت وابستگی‌ها امتیاز میده.
[https://scorecard.dev](https://scorecard.dev/)
***2️⃣***
Gitleaks :
برای پیدا کردن اطلاعات حساسی که اشتباهی داخل پروژه قرار گرفته‌، مثل کلید API، رمز عبور، توکن و کلید خصوصی.
[https://github.com/gitleaks/gitleaks](https://github.com/gitleaks/gitleaks)
***3️⃣***
OSV-Scanner :
وابستگی‌های یک پروژه را بررسی میکنه تا مشخص بشه از نسخه‌های آسیب‌پذیر استفاده میکنه یا نه.
[https://google.github.io/osv-scanner](https://google.github.io/osv-scanner)
***4️⃣***
Trivy :
یک اسکنر چندمنظوره برای پیدا کردن آسیب‌پذیری، اطلاعات حساس، مشکلات امنیتی در پروژه، فایل‌ها و...
[https://trivy.dev/](https://trivy.dev/)
***5️⃣***
Socket :
روی امنیت بسته‌ها و کتابخونه‌های متن‌باز تمرکز داره.
[https://socket.dev](https://socket.dev/)
***6️⃣***
Semgrep :
کد پروژه رو بررسی میکنه و به دنبال الگوهای خطرناک و خطاهای امنیتی رایج میگرده. برای پیدا کردن مشکلات داخل خود کد کاربردیه.
[https://semgrep.dev](https://semgrep.dev/)
***7️⃣***
GitHub Security :
خود گیت‌هابم هم ابزارهای امنیتی داخلی داره.
[https://github.com/security](https://github.com/security)
***8️⃣***
 بررسی اصالت و منشا فایل‌ها :
گاهی مشکل خود کد نیست، باید بدونیم فایل اجرایی یا بسته‌ای که دانلود کردیم واقعا از همون پروژه ساخته شده یا نه؟
فناوری‌هایی مثل Sigstore، SLSA و GitHub Attestations برای ثبت و بررسی منشا فایل‌ها و نحوه ساخته‌شدنشون استفاده میشه.
***🔗***
 
[https://www.sigstore.dev](https://www.sigstore.dev/)
