** ابزار کاربردی برای مانیتورینگ VPS، سرور و سرویس‌های آنلاین**

***1️⃣***
Uptime Kuma :
یک ابزار رایگان و اپن‌سورس برای بررسی آنلاین بودن سایت‌ها، APIها، پورت‌ها، DNS و سرویس‌های مختلف. تاریخچه قطعی و زمان پاسخ‌گویی رو ثبت می‌کنه و امکان ارسال اعلان از طریق تلگرام، Discord و ایمیل رو داره.
***🔗***
 
[https://github.com/louislam/uptime-kuma](https://github.com/louislam/uptime-kuma)
***2️⃣***
Beszel :
یک ابزار سبک برای مانیتورینگ VPS و سرور با رابط کاربری ساده. مصرف CPU و RAM، فضای دیسک و ترافیک شبکه رو نمایش میده و از مانیتورینگ Docker و Podman، ثبت اطلاعات تاریخی و ارسال هشدار پشتیبانی میکنه.
***🔗***
 
[https://beszel.dev/](https://beszel.dev/)
***3️⃣***
Netdata :
برای مانیتورینگ دقیق و لحظه‌ای زیرساخت مناسبه. اطلاعاتی مثل مصرف CPU، RAM، فعالیت پردازش‌ها، شبکه و دیسک رو نمایش میده و قابلیت مانیتورینگ Docker، دیتابیس و سرویس‌ها رو داره. از MCP هم برای اتصال به دستیارهای هوش مصنوعی پشتیبانی میکنه.
***🔗***
 
[https://www.netdata.cloud/](https://www.netdata.cloud/)
***4️⃣***
Better Stack :
یک سرویس ابری برای بررسی وضعیت سایت و API از خارج سرور. از مانیتورینگ DNS، SSL و Ping پشتیبانی میکنه و امکان ثبت خطا، ساخت Status Page عمومی و ارسال اعلان هنگام قطعی رو فراهم میکنه.
***🔗***
 
[https://betterstack.com/uptime](https://betterstack.com/uptime)
***5️⃣***
 
[Healthchecks.io](http://Healthchecks.io/)
 :
برای نظارت بر اجرای صحیح کارهای زمان‌بندی‌شده مثل Cron Job، اسکریپت‌ها و بکاپ‌ها مناسبه. با قرار دادن یک درخواست Ping داخل اسکریپت، در صورت اجرا نشدن یا نرسیدن گزارش موفقیت در زمان تعیین‌شده، هشدار دریافت می‌کنی. پلن رایگان امکان نظارت بر 20 تسک رو میده.
***🔗***
 
[https://healthchecks.io](https://healthchecks.io/)
***6️⃣***
Gatus :
یک ابزار اپن‌سورس برای مانیتورینگ سرویس‌ها که تنظیماتش از طریق فایل‌های YAML انجام میشه. از بررسی HTTP، TCP، DNS و TLS پشتیبانی میکنه و امکان تعریف شرایط اختصاصی برای تشخیص خطا، ارسال هشدار و ساخت Status Page رو داره.
***🔗***
 
[https://gatus.io](https://gatus.io/)
***7️⃣***
Glances :
یک ابزار سبک برای نمایش وضعیت منابع سیستم با رابط ترمینال و داشبورد تحت وب. مصرف CPU و RAM، پردازش‌ها، شبکه و دیسک رو بررسی میکنه و با پشتیبانی از API و MCP امکان اتصال به دستیارهای هوش مصنوعی رو هم فراهم میکنه.
***🔗***
 
[https://glances.readthedocs.io](https://glances.readthedocs.io/)
