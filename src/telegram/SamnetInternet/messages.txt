هر اینترنتی که قطع می‌کنن، VPN و کانفیگ جدید می‌سازیم.  
هر جنایتی که می‌کنن، فقط سقوطشون رو نزدیک‌تر می‌کنه.

### 🕒 2026-03-20 03:13:26 UTC
***🗂***
 پروژه range-scout آپدیت شد کار ادمین عزیز گروه پدی. 
***🔥***
 نسخه v0.1.3
***🎯***
 اضافه شدن بارگذاری دستی تارگت برای اسکن:
• حالا علاوه بر دریافت خودکار رنج‌ها، می‌تونید رنج یا IPها را دستی هم وارد کنید
• پشتیبانی از Import TXT برای وارد کردن رنج‌ها و IPها از فایل
• پشتیبانی از Paste Targets برای Paste مستقیم داخل TUI
• هر خط می‌تونه یک IPv4 CIDR یا یک Single IP باشه
• خط‌های خالی و کامنت‌های # نادیده گرفته می‌شن
***🇮🇷***
 مخصوص کاربرهای داخل ایران:
• اگر API fetch برای شما در دسترس نیست یا از داخل ایران درست جواب نمی‌دهد، دیگر بلاک نمی‌شوید
• حالا می‌توانید رنج‌ها را خودتان Paste کنید یا با TXT import وارد برنامه کنید
• اسکن فقط روی همان رنج‌ها و IPهای واردشده انجام می‌شود
• برای تارگت‌های دستی هم مثل حالت خودکار، امکان انتخاب قبل از اسکن وجود دارد
***🧭***
 بهبود تجربه کاربری:
• سه روش مشخص برای لود تارگت:
• Automatic API Fetch
• Import TXT
• Paste Targets
• IPهای تکی در رابط به شکل طبیعی نمایش داده می‌شوند، نه /32
• ذخیره تارگت‌ها به صورت txt ساده‌تر و شفاف‌تر شده
***📦***
 بهبود ریلیز:
• علاوه بر فایل‌های فشرده، نسخه‌های uncompressed باینری هم داخل ریلیز قرار می‌گیرند
