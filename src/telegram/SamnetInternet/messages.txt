### 🕒 2026-03-20 03:13:26 UTC
***🗂***
 پروژه range-scout آپدیت شد کار ادمین عزیز گروه پدی. 
***🔥***
 نسخه v0.1.3
***🎯***
 اضافه شدن بارگذاری دستی تارگت برای اسکن:
• حالا علاوه بر دریافت خودکار رنج‌ها، می‌تونید رنج یا IPها را دستی هم وارد کنید
• پشتیبانی از Import TXT برای وارد کردن رنج‌ها و IPها از فایل
• پشتیبانی از Paste Targets برای Paste مستقیم داخل TUI
• هر خط می‌تونه یک IPv4 CIDR یا یک Single IP باشه
• خط‌های خالی و کامنت‌های # نادیده گرفته می‌شن
***🇮🇷***
 مخصوص کاربرهای داخل ایران:
• اگر API fetch برای شما در دسترس نیست یا از داخل ایران درست جواب نمی‌دهد، دیگر بلاک نمی‌شوید
• حالا می‌توانید رنج‌ها را خودتان Paste کنید یا با TXT import وارد برنامه کنید
• اسکن فقط روی همان رنج‌ها و IPهای واردشده انجام می‌شود
• برای تارگت‌های دستی هم مثل حالت خودکار، امکان انتخاب قبل از اسکن وجود دارد
***🧭***
 بهبود تجربه کاربری:
• سه روش مشخص برای لود تارگت:
• Automatic API Fetch
• Import TXT
• Paste Targets
• IPهای تکی در رابط به شکل طبیعی نمایش داده می‌شوند، نه /32
• ذخیره تارگت‌ها به صورت txt ساده‌تر و شفاف‌تر شده
***📦***
 بهبود ریلیز:
• علاوه بر فایل‌های فشرده، نسخه‌های uncompressed باینری هم داخل ریلیز قرار می‌گیرند

دوستان عزیز برنامه V2Box برای iOS اخیرا اپدیت اضافه شدن پروتکل DNSTT رو داده. باید از اپ استور اپدیت بشه. به هر صورت این آموزشش هست. 
باید اطلاعات خام DNStt ساده رو داشته باشید، بعد دستی اضافه کنید، و یا QRCode اسکن کنید، فیلداش ایناست
**Remarks:**
هر چی خواستید بدید
**Address:**
آدرس رکورد NSای که روی دامین ساختید
**DNS Servers:**
این‌جا باید از این DNSهایی که در سطح نت پیدا می‌کنید قرار بدید
**PubKey:**
این رکورد هم باید PubKeyهایی که DNSttها دارن و رایج هست رو بدید، هر DNStt یه Public Key داره، که اون رو باید این‌جا وارد کنید.
برای اطلاعات خام سرور میتونین این پست رو ببینید یا به گروه کامیونیتی مون 
[@Samnetgroup](https://t.me/Samnetgroup)
 بپیوندید که در تاپیک کانفیگ بچه های فعال براتون کانفیگ بفرستند.

### 🕒 2026-03-19 16:48:26 UTC
***🗂️***
 پروژه dnstm-setup اپدیت مخصوص رفع ایرادات و باگ ها 
***🔥***
 نسخه v1.3.1
`***🌐***`
ساخت خودکار رکوردهای DNS با Cloudflare API:
• فقط توکن API وارد کنید — رکوردهای NS و A خودکار ساخته میشن
• تشخیص خودکار Zone ID دامنه
• اگه رکورد از قبل وجود داشته باشه آپدیت میکنه نه duplicate 
***🛡️***
 امنیت DNS و پایداری سرور:
• سرور دیگه هیچوقت قفل نمیشه — DNS خودکار بازیابی میشه
• پشتیبان‌گیری خودکار از resolv.conf و sshd_config قبل از تغییرات
• قفل resolv.conf با chattr — هیچ پروسه‌ای نمیتونه خرابش کنه
• تشخیص خودکار DNS خراب و تعمیر فوری
***🔌***
 رفع کامل بک‌اند Xray/3x-ui:
• سازگاری کامل با 3x-ui نسخه 2.0+ (رمز هش شده bcrypt)
• تنظیم پورت و رمز از طریق باینری x-ui (نه فقط دیتابیس)
• تشخیص خودکار HTTPS و base path پنل
***🔧***
 رفع مشکل NoizDNS:
• باینری‌ها از ریپوی خودم هاست میشن 
• اعتبارسنجی باینری با دستور file به جای -help
***⚡***
 رفع microsocks (GLIBC):
• تشخیص خودکار ناسازگاری GLIBC بعد از نصب
• منتظر آزاد شدن قفل dpkg میمونه (unattended-upgrades)
• کامپایل خودکار از سورس روی سیستم‌های قدیمی
***🔑***
 سازگاری SSH:
• رفع خطای Bitvise: no match for method mac algo
• اضافه شدن MAC های non-ETM SHA2 به عنوان فالبک
***🆕***
 گزینه آپدیت در منوی مدیریت:
• گزینه 10 در منوی TUI یا دستور --update
• بررسی خودکار نسخه جدید از گیت‌هاب
• دانلود، اعتبارسنجی و ری‌استارت خودکار
***📋***
 منوی مدیریت کامل:
• افزودن/حذف تانل و دامنه
• بک‌اند Xray (VLESS/VMess/Trojan/Shadowsocks)
• تغییر DNSTT MTU
• آپدیت، هاردنینگ، حذف نصب
