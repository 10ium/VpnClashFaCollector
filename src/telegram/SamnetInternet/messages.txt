 cfray v1.1 
یه ابزار تک‌فایلی پایتونی که همه چیز رو برای مدیریت کانفیگ‌های VLESS و V2ray پشت Cloudflare یکجا جمع کرده. اسکن و رتبه‌بندی کانفیگ‌ها، پیدا کردن آی‌پی تمیز از بین ۱.۵ میلیون آی‌پی Cloudflare، دور زدن فیلترینگ عمیق با پایپلاین فرگمنت، نصب خودکار سرور Xray روی VPS، ساخت Worker برای SNI تمیز، و مدیریت کامل سرور — همه از یه منوی تعاملی ساده. فقط Python 3.8+ لازمه، بدون هیچ وابستگی.

### 🕒 2026-05-26 13:26:20 UTC
***⚡***
 MTProxyMax — پروکسی تلگرام با موتور راست Rust
خیلیا بهم گفتن این پروکسی از بقیه خیلی سریع‌تره. دلیلش اینه:
موتور telemt 3.x کامل با Rust نوشته شده و با LTO کامپایل میشه یعنی throughput بالا با مصرف حداقلی رم. جایی که پروکسی‌های پایتونی یا Go زیر بار کند میشن، این یکی راحت جواب میده.
***🛡️***
 و همین طور FakeTLS V2 — ترافیک شبیه HTTPS واقعی. DPI نمی‌تونه تشخیص بده.
***👥***
 مدیریت کاربر — هر کاربر secret مجزا با محدودیت اتصال، دستگاه، محدودیت حجم و تاریخ انقضا برای هر لینک پروکسی
***🤖***
 ربات تلگرام — ۱۷ دستور. مدیریت کامل از گوشی + هشدار قطعی + ری‌استارت خودکار.
***🔗***
 زنجیره پروکسی — ترافیک از SOCKS5 رد بشه برای لایه اضافی امنیت.
***📊***
 مانیتورینگ — Prometheus metrics + داشبورد TUI تعاملی.
***🐳***
 Docker — ایمیج آماده amd64 + arm64. نصب در چند ثانیه.
***⭐***
 
[https://github.com/SamNet-dev/MTProxyMax](https://github.com/SamNet-dev/MTProxyMax)
